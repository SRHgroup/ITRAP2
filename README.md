R workflow for denoising of sigle-cell pMHC data generated by barcoded pMHC multimers.

The workflow is intended for T-cell scientists that are Seurat users, that want to analyse their pMHC data. We expect you to store your raw pMHC counts in object@assays$pMHC

The package employs a specific type of mean centering and sd scaling, where means and sds are calculated without outliers. Used as an alternarive to meadian and mad, sinse in sparse datasets they often end up as 0.
Scaled pMHC counts matrix will be stored in object@assays$pMHC@scale.data
![Screenshot 2024-03-06 at 12 43 22](https://github.com/SRHgroup/pmhc_denioseR/assets/45093246/8b7fbe80-e8b3-4af4-b496-9133cd167367)

```R
ScaleDataNoOutliers(object)
```

Fpr the next step we expect you to store your clonotype information in object@metadata$clone_id. We will perform extra denoising step on every expanded clone.
Next scaled counts are subjected to smoothing using local regression. Scaled matrix will be updated in object@assays$pMHC@scale.data.

```R
smooth_pmhc(object)
```

Next we want to label each expanded clone with pMHC specificity, we do that by doing the outlier search within your pMHC panel, since we look at the relative to your pMHC panel values, 
we expect that you have at least 20 different pMHC barcodes in your experiment, otherwise the pMHC assigments with this functions might be flawed. For the assigments we also want you to
have a table with pMHC barcode annotations, that you store in object@misc$pmhc. here is an example
![Screenshot 2024-03-06 at 12 42 55](https://github.com/SRHgroup/pmhc_denioseR/assets/45093246/400afcd4-f1d9-4f91-8ed9-785fa70af79a)
This is done in case the same barcode corresponds to differebt pMHC within the same experiment, but in different donors, that were demultiplexed by hashing antobodies. In this simple example rownames in the
matrix is the same as the pMHC.

```R
assign_pmhc(object)
```

By the end of this step your object@meta.data will have a column called  pMHC_classification, it can have multiple pMHC recorded there, in case the clone is cross reacvite.
